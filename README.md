Portafolio Personal - Tarea
Este es un proyecto de portafolio personal  asignado por la universidad creado utilizando EJS, JavaScript, Node.js, CSS y SQLite. El portafolio incluye una sección de contacto con 
reCAPTCHA y la funcionalidad para enviar un correo electrónico al registrarse. Además, permite el registro a través de Google.

Características
EJS: Utilizado para renderizar las vistas del servidor.
JavaScript: Lógica del lado del cliente y del servidor.
Node.js: Entorno de ejecución para el servidor.
CSS: Estilos para la interfaz de usuario.
SQLite: Base de datos ligera para almacenar información de usuarios.
reCAPTCHA: Protección contra bots en el formulario de contacto.
Correo Electrónico: Envío de correos electrónicos al registrarse.
Registro con Google: Autenticación de usuarios a través de Google.
